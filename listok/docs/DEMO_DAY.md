# Підготовка до захисту

## За день до захисту
- [ ] Відкрити сайт на Render, визначити 1 рослину: працює, час < 15 с.
- [ ] Відкрити `/healthz`: `gemini_configured: true`, `storage: "supabase"`, `storage_ok: true`, `mock_mode: false`.
- [ ] Google AI Studio → Usage / Rate limits: квота не вичерпана.
- [ ] Supabase: проєкт не на паузі (Free ставить на паузу після 7 днів без запитів).
- [ ] У «Моїх рослинах» 4–6 гарних записів (видалити тестові й невдалі).
- [ ] Прогнати 3–4 демо-фото: на кожному правильна назва і впевненість від 85 %.
- [ ] Локальний запасний варіант: `run_local.bat` запускається, сторінка відкривається.
- [ ] Демо-фото є і на телефоні (галерея), і на ноутбуці (папка demo_photos).
- [ ] Зарядити телефон і ноутбук; перевірити мобільний інтернет як запасний (роздача з телефона).

## У день захисту
- [ ] За 5–10 хв до пари відкрити сайт на ноутбуці і на телефоні — Render «прокинеться».
      Не закривати вкладку; якщо до показу більше 15 хв, оновити сторінку ще раз.
- [ ] Перевірити, що вибрано режим «Швидко».
- [ ] Відкрити вкладки: сайт, «Мої рослини», «Як це працює», Supabase Table Editor, GitHub.

## Сценарій показу (3–4 хв)
1. Головна сторінка на ноутбуці → перетягнути фото монстери → картка (назва, проблеми, догляд, токсичність, час і ціна).
2. Зберегти → «Мої рослини»: статистика, фільтр «Небезпечні для тварин».
3. Телефон: «Зробити фото» → сфотографувати живу рослину → результат.
4. Показати обробку помилок: завантажити не-зображення (напр. PDF) → зрозуміле повідомлення.
5. «Як це працює»: схема хмарних сервісів і таблиця цін.
6. Supabase Table Editor → таблиця `plants` з'явився новий рядок.

## Якщо щось пішло не так
| Ситуація | Що робити |
|---|---|
| Сайт довго відкривається | Render прокидається, зачекати до 1 хв |
| «Перевищено ліміт Gemini API» | Показати повторно вже визначене фото (з кешу, миттєво), або запустити локально з іншим ключем |
| Немає інтернету в аудиторії | Роздати інтернет з телефона |
| Render не працює | Запустити `run_local.bat`, показати на `127.0.0.1:5000` |
| Supabase на паузі | Supabase → проєкт → Restore (1–2 хв); тим часом показувати визначення без збереження |
