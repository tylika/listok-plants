# Фото для демонстрації і замірів

Покладіть сюди 4–8 власних фото кімнатних рослин. Назва файлу = латинська назва через дефіс:

| Файл | Рослина |
|---|---|
| `monstera-deliciosa.jpg` | Монстера (впізнається майже завжди, токсична для тварин) |
| `spathiphyllum-wallisii.jpg` | Спатифілум (добре видно квітку) |
| `chlorophytum-comosum.jpg` | Хлорофітум (безпечний для котів — гарний контраст) |
| `zamioculcas-zamiifolia.jpg` | Заміокулькас |
| `aloe-vera.jpg` | Алое віра |
| `ficus-elastica.jpg` | Фікус каучуконосний |
| `problem__....jpg` | Будь-яка рослина з пожовклим/плямистим листком — для демонстрації «проблем» |

Сансев'єрію краще не брати для замірів: ботаніки перенесли її в рід *Dracaena*,
тому модель може відповісти `Dracaena trifasciata`, і скрипт зарахує це як помилку.

Фото: денне світло, рослина займає більшу частину кадру, без сильного розмиття.
